# Dash Client

## Запуск готового JAR на Windows

Готовая локальная поставка содержит `DashClient-RTX.bat`, его вспомогательные скрипты, `dash-client-1.0.0.jar` и библиотеки Fabric в `runtime`. Запустите BAT из этой папки. Проект и исходный ZIP для запуска не нужны.

Этот профиль использует уже установленные файлы Minecraft 1.21.11, JDK 25 и Fabric Loader 0.19.5 из локальной поставки. Если Minecraft расположен вне стандартных папок, укажите `DASH_MINECRAFT_HOME` с путём к папке, содержащей `assets`, `libraries` и `versions`. Настройки и сохранения профиля Dash хранятся отдельно от базовой установки Minecraft.

Прямой запуск из BAT предназначен для автономной игры. Для игры с авторизацией Microsoft используйте обычный профиль Fabric в Minecraft Launcher и установите туда JAR Dash и его зависимости.

## Сборка и запуск из исходного проекта на Windows

1. Распакуйте весь проект и запустите `DashClient-RTX.bat` из распакованной папки. По умолчанию профиль RTX использует OpenGL и ограничение 840 FPS.
2. На компьютере должны быть JDK 25, локальный Gradle 9.7.1 и уже заполненный кэш проекта для Minecraft 1.21.11 и Fabric Loader 0.19.5, включая Minecraft assets. Лаунчер использует `JAVA_HOME` или ищет JDK в стандартных папках. Для Gradle он использует `%USERPROFILE%\.gradle` или папку из `GRADLE_USER_HOME`. Если Gradle установлен отдельно, укажите его папку в `GRADLE_HOME`.
3. Sodium загружается из локального профиля или кэша Dash. Чтобы использовать другой уже имеющийся экземпляр, задайте `DASH_SODIUM_JAR` абсолютным путём к совместимому JAR в окне CMD перед запуском BAT.

Лаунчер запускает Gradle в офлайн-режиме и выдаёт ошибку при отсутствии необходимых локальных компонентов. Дистрибутив Gradle, игровой кэш и сторонние моды в архив исходного кода не входят.

Профиль RTX задаёт в настройках графики текущего пользователя Windows режим **Высокая производительность** для конкретного `java.exe` из выбранного JDK 25. Windows применяет эту настройку и к другим программам, которые запускают тот же исполняемый файл. Активный GPU указан в `run/rtx-profile/logs/latest.log` в строке `OpenGL Renderer`.

Предел 840 FPS применяется при значении **Без ограничений** в настройках частоты кадров Minecraft. VSync или выбранное в самой игре меньшее ограничение может дополнительно снизить FPS.

## Pause

Войдите в одиночный мир без публикации по LAN и нажмите **Pause** в меню Dash. Модули и интерфейс Dash отключаются до завершения сеанса. Minecraft продолжает работу в открытом мире.

Сборка для уже подготовленного локального окружения — `gradlew.bat --offline clean build`.
