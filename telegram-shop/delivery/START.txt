Запуск Dash Client

1. Збережіть отриманий файл PythonLoaderDC.py у свою папку на Windows.
2. На ПК мають бути Python 3.11 або новіший з IDLE, Java 25 x64 та вже встановлений Minecraft Java 1.21.11 з ресурсами.
3. Відкрийте IDLE, виберіть File → Open та відкрийте PythonLoaderDC.py.
4. Натисніть F5. Лоадер перевірить версію на GitHub, завантажить готовий JAR і потрібні бібліотеки та запустить Java.
5. На першому запуску виберіть нікнейм у вікні Minecraft.

Через CMD можна запустити командою
py -3 "C:\шлях\до\PythonLoaderDC.py"

Для перевірки оновлення без запуску гри
py -3 "C:\шлях\до\PythonLoaderDC.py" --update-only

Дані зберігаються у папці DashClientDirect\1.21.11 вашого профілю Windows, наприклад C:\Users\USER\DashClientDirect\1.21.11. JAR і бібліотеки залишаються локально для повторних запусків. Код проєкту та ZIP лоадер не завантажує.

Цей комплект має одиночний профіль Minecraft. Автоматичний вхід на сервери не налаштований. На перевіреному ПК він запускався на RTX 5070 з лімітом 840 FPS. Фактичний FPS залежить від компʼютера та світу.

Для повторного отримання файла натисніть «Моя покупка» або введіть /download.
Для питання щодо оплати введіть /paysupport.
