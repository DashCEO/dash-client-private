# Магазин Dash Client у Telegram

Бот видає перевірений PythonLoaderDC.py і текстову інструкцію після оплати через Telegram Stars. Код клієнта та спосіб запуску всередині отриманого лоадера збережено.

## Ціни та поведінка

- Безстрокова копія коштує 99 XTR.
- Chrome, Art і zeff дають знижку 15%. Регістр літер не має значення.
- Ціна зі знижкою становить 84 XTR. Результат 84,15 округлено до цілої зірки на користь покупця.
- Розрахунок гривневої ціни — 99 грн × 0,85 = 84,15 грн. Гривні та Stars мають окремі ціни.
- Telegram ID 6662507956 отримує комплект без платежу.
- Є кнопки «Купити», «Промокод», «Оплата», «Моя покупка».
- Після перезапуску бота покупки, промокоди, черга видачі й позиція polling зберігаються у SQLite.

JAR та вихідний код Dash опубліковані у відкритому GitHub. Купівля в цьому боті надає видачу комплекту й повторне отримання через бота. Перевірку ліцензії всередині клієнта не додано.

Вкладений лоадер запускає одиночний профіль Minecraft 1.21.11. Це зазначено у картці товару, умовах та інструкції до оплати.

## Запуск

Потрібен Python 3.11 або новіший. Зовнішніх Python-залежностей немає.

1. Створіть бота через @BotFather командою /newbot.
2. Скопіюйте .env.example у .env у цій папці.
3. У .env запишіть отриманий токен після BOT_TOKEN=. Токен залишається лише на вашому сервері чи ПК.
4. Перевірте комплект.

    python bot.py --check
    python -m unittest discover -v

5. Запустіть бота.

    python bot.py

На Windows команди можна виконувати як py -3 bot.py. Бот працює, поки процес запущений і має інтернет. GitHub зберігає код, а процес потрібно запускати на своєму ПК або сервері.

У бота має бути вільний polling. Якщо для нього налаштовано webhook, запуск повідомить про це. Скрипт не скидає наявні оновлення. Два процеси з однією локальною базою одночасно не запускаються.

## Команди

| Команда | Дія |
|---|---|
| /start, /buy | Картка товару |
| /promo Chrome | Застосувати промокод |
| /pay | Умови та рахунок у Stars |
| /download | Повторна видача після покупки або для адміністратора |
| /terms | Умови придбання |
| /paysupport, /support | Контакт адміністратора |
| /cancel | Скасувати введення промокоду |
| /refund ID_замовлення | Повернення Stars, лише для адміністратора |

Оплата здійснюється за правилами Telegram для цифрових товарів. У рахунку використано XTR, один елемент prices та порожній provider_token. [Telegram Stars](https://core.telegram.org/bots/payments-stars)

## Перевірка та видача

Бот звіряє користувача, замовлення, валюту та суму перед оплатою. Файл видається після successful_payment. Ідентифікатор платежу зберігається для захисту від повторної обробки та повернень.

Видача виконується в окремій черзі. При недоступності Telegram бот повторить її після затримки. Якщо процес завершиться між фактичним надсиланням і записом результату в SQLite, Telegram може показати повторний файл. Повторне списання бот не ініціює. Покупець також може використати /download.

Зберігайте папку data між перезапусками. Для резервної копії зупиніть бота і скопіюйте SQLite-файл. У базі є Telegram ID, замовлення й ідентифікатори платежів. База та .env виключені з Git.

Реальні платежі потребують токена бота й перевірки в окремому тестовому середовищі Telegram. BOT_TEST_MODE=1 вмикає тестовий endpoint для відповідного тестового токена. Після перевірки використовуйте production-токен та BOT_TEST_MODE=0. [Тестове середовище](https://core.telegram.org/bots/webapps#testing-mini-apps)
