# Telegram-магазин Dash Client

Бот приймає Telegram Stars та видає Python-лоадер з короткою інструкцією українською або російською.

- Ціна — 99 XTR. З промокодом — 84 XTR після округлення.
- Розрахунок ціни у гривнях — 99 × 0,85 = 84,15 грн. Stars мають окрему ціну.
- Адміністратор з Telegram ID 6662507956 отримує комплект без оплати.
- Кнопки — «Купити», «Промокод», «Оплата», «Моя покупка», «Мова».
- Покупки та мова зберігаються після перезапуску.

Потрібен Python 3.11 або новіший. Додаткових бібліотек немає.

1. Створи бота через @BotFather командою /newbot.
2. Скопіюй .env.example у .env.
3. Запиши токен у BOT_TOKEN. У PROMO_CODES додай дозволені коди через кому. Файл .env залишається тільки на машині, де працює бот.
4. Перевір файли й тести.

   ```console
   python bot.py --check
   python -m unittest discover -v
   ```

5. Запусти бота.

   ```console
   python bot.py
   ```

На Windows замість python можна використовувати py -3. Процес має залишатися запущеним. GitHub зберігає код і сам бота не запускає.

| Команда | Дія |
|---|---|
| /start або /buy | Відкрити магазин |
| /promo "код" | Застосувати власний промокод |
| /pay | Прийняти умови й отримати рахунок |
| /download | Повторно отримати покупку |
| /language або /launguage | Вибрати українську або російську |
| /terms | Прочитати умови |
| /paysupport або /support | Звернутися до адміністратора |
| /cancel | Скасувати введення промокоду |
| /refund ID_замовлення | Повернути Stars, доступно адміністратору |

Файл надсилається після підтвердженого successful_payment. Невдала видача повторюється автоматично. Якщо збій стався після відправлення, але до запису результату, можливе повторне повідомлення. Платіж повторно не створюється.

Зберігай папку data. Для її резервної копії спочатку зупини бота. Токен, промокоди та база покупців виключені з Git.

Поточна збірка призначена для одиночної гри. Потрібні Windows x64, Java 25 і встановлений Minecraft Java 1.21.11. Лоадер зберігає готовий JAR та бібліотеки на ПК. Код і JAR публічні, тому покупка тут надає видачу комплекту через бота.

Реальні платежі слід перевірити у тестовому середовищі Telegram. Для тестового токена встанови BOT_TEST_MODE=1, для звичайного — 0. [Telegram Stars](https://core.telegram.org/bots/payments-stars) · [Тестове середовище](https://core.telegram.org/bots/webapps#testing-mini-apps)
